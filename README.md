# Ground Floor Academy

AI Agentic Infrastructure Masterclass — branded design preview.

Open `index.html` locally for offline learning, or use the GitHub Pages site once enabled. The self-contained HTML includes lessons, simulations, local progress storage, and the downloadable engineering lab kit. Progress is stored per browser and origin; use the course export/import controls to move progress between local and hosted copies.

This is the supplied Design Kickoff preview, not the final brand release. Official logo/favicons and further design/accessibility work remain outstanding as documented in the original package.

## GitHub Pages

In Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, and Save.
